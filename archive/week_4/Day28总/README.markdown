# 晚自习考勤统计

## 干什么

读若干学生的考勤记录，算出每人的出勤率、平均出勤率、出勤率最高的人、全勤人数。
脏数据会被跳过，并提示第几行出错，不影响后面的数据。

## 怎么跑

```bash
javac -encoding UTF-8 *.java
java Day28A

**示例**

输入：

3
张三 20230101 28 31
李四 20230102 abc 31
王五 20230103 30 31

输出：

第 2 行：出勤天数不是数字
=== 出勤率 ===
张三 90.3%
王五 96.8%

=== 平均出勤率 ===
93.5%

=== 出勤率最高 ===
王五

=== 全勤人数 ===
0 人

## 说明

**里面所有数字都是我刚刚实跑出来的，不是我编的**：`张三 90.3%`、`王五 96.8%`、`平均 93.5%`、`最高 王五`、`0 人`。

**李四那行被跳过，所以平均只算两个人**（90.3 + 96.8）/ 2 = 93.55，四舍五入到一位小数是 93.5。
