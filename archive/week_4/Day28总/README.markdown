# 晚自习考勤统计

## 干什么

读若干学生的考勤记录，算出每人的出勤率、平均出勤率、出勤率最高的人、全勤人数。
脏数据会被跳过，并提示第几行出错，不影响后面的数据。

## 怎么跑

```
javac -encoding UTF-8 *.java
java Day28A
```

## 输入格式

第一行：学生人数 n

后面 n 行：姓名 学号 出勤天数 总天数

校验规则：

- 学号必须是 8 位数字
- 出勤天数 0~31
- 总天数 1~31
- 出勤天数不能大于总天数

## 示例

输入：

```
3
张三 20230101 28 31
李四 20230102 abc 31
王五 20230103 30 31
```

输出：

```
第 2 行：出勤天数不是数字
=== 出勤率 ===
张三 90.3%
王五 96.8%

=== 平均出勤率 ===
93.5%

=== 出勤率最高 ===
王五

=== 全勤人数 ===
0 人
```

第 2 行是故意写坏的（姓名和学号都对，出勤天数写成 abc），
用来演示坏数据不会让程序中断，也不会污染后面的统计。

## 已知限制

- 全部数据都坏时，「出勤率」那一段下面是空的，但程序不会崩
- 出勤率并列最高时，取先出现的那个
